Для пользователей:
invoice_helper - windows приложение, призванное ускорить процесс ручного заполнения прихода товаров исключительно по названию товаров в номенклатуре в программе 1С.

Передаёте в приложение ваши pdf/сканы, сдержащие накладные, программа пытается найти таблицы с товарами. В случае успеха позволяет открыть дополнительное окно-оверлей (поверх других окон) с удобным интерфейсом копирования названий/цен (с возможностью указания наценки/ндс/...).

В оверлее выбираем нужный товар, кликаем на слова, которые хотим скопировать (порядок учитывается) или копируем полностью (если в номеклатуре и в таблице названия совпадают полностью) - текст попадет в буфер обмена. Кликаем на поле ввода названия в 1с программе и на клавиатуре нажимаем 'ctrl + v'

Для разработчиков:
Если коротко, из чего состоит и как работает это приложение:
Начну с backend части: parser.exe - простейший .py скрипт на базе библиотеки Dedoc и Tesseract OCR + всё необходимое окружение. Работает по принципу CLI (parser.exe --file "path/to/file"). Скрипт ищет только таблицы , имеющие в верхней половине строку из последовательности ячеек 1,2,3 (или с буквами). Исходный код и инструкцию по сборке прикреплю позже.
UI полностью на Flutter(dart).
Открывая файл(ы), приложение для каждого файла выполняет parser.exe --file "path/to/file", получив таблицы, запоминает их пока приложение открыто.

В приложении, вероятно, не мало проблем. Критических я не обнаружил, но оптимизационых перспектив достаточно.

Как собрать самостоятельно:
0.5) Для сборки на вашем компе придётся отредактировать путь "includePath" в .vscode\c_cpp_properties.json (библиотека window_manager_plus_v2 имеет кривые пути)

1) 'git clone {repo}'
2) выполняем пункт 0.5) 
3) 'cd invoice_project/flutter_app'
4) 'flutter clean'
5) 'flutter pub get'
6) 'flutter build windows'
7) Качаем готовый/собираем самостоятельно parser.exe
8) В корне flutter приложения создаём папку backend, в которую помещаем parser.exe
8.5) качаем и устанавливаем Tesseract-OCR (например [отсюда](https://docs.coro.net/featured/agent/install-tesseract-windows/) ) , корневую папку переименовываем и кидаем в папку backend
9) Готово - запускаем flutter_app.exe.
