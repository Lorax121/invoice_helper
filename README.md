# Invoice Helper

**Invoice Helper** — это Windows-приложение, призванное ускорить процесс ручного заполнения прихода товаров в программе 1С, используя только названия товаров из номенклатуры.

## 🎯 Для пользователей

Приложение работает по простому принципу:

1.  **Передайте в приложение ваши PDF-файлы или сканы**, содержащие накладные. Программа попытается найти в них таблицы с товарами.
2.  В случае успеха, откроется **дополнительное окно-оверлей** (поверх всех других окон) с удобным интерфейсом для копирования названий и цен. В нём также можно указать наценку/НДС/... .
3.  В оверлее выберите нужный товар и **кликните на слова**, которые хотите скопировать (порядок кликов учитывается), или скопируйте название целиком.
4.  Выбранный текст попадёт в буфер обмена. Перейдите в программу 1С, кликните на поле ввода названия и нажмите **`Ctrl + V`**.

## 👨‍💻 Для разработчиков

### Архитектура и принцип работы

Если коротко, из чего состоит и как работает это приложение:

*   **Backend**: `parser.exe` — простейший Python-скрипт на базе библиотеки **Dedoc** и **Tesseract OCR** со всем необходимым окружением.
    *   Работает по принципу CLI: `parser.exe --file "path/to/file"`.
    *   Скрипт ищет таблицы, имеющие в верхней половине строку из последовательности ячеек `1, 2, 3...` (или с буквами).
    *   Исходный код и инструкция по сборке парсера будут приложены позже.

*   **Frontend (UI)**: Полностью написан на **Flutter (Dart)**.

*   **Взаимодействие**: При открытии файла(ов) Flutter-приложение для каждого из них выполняет команду `parser.exe --file "path/to/file"`. Полученные таблицы хранятся в памяти, пока приложение запущено.

> **Примечание**: В приложении, вероятно, не мало проблем. Критических я не обнаружил, но перспектив для оптимизации достаточно.

### Инструкция по сборке

1.  **Важно!** Для сборки на вашем компьютере придётся отредактировать путь `includePath` в файле `.vscode\c_cpp_properties.json` (из-за некорректных путей в библиотеке `window_manager_plus_v2`).

2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Lorax121/invoice_helper.git
    ```

3.  Перейдите в папку проекта:
    ```bash
    cd invoice_project/flutter_app
    ```

4.  Выполните очистку и загрузку зависимостей:
    ```bash
    flutter clean
    flutter pub get
    ```

5.  Соберите Windows-приложение:
    ```bash
    flutter build windows
    ```

6.  Скачайте готовый или соберите самостоятельно `parser.exe`.

7.  В корневой папке Flutter-приложения (`flutter_app`) создайте директорию `backend` и поместите в неё `parser.exe`.

8.  Скачайте и установите **Tesseract-OCR** (например, [отсюда](https://docs.coro.net/featured/agent/install-tesseract-windows/)). Корневую папку с установленным Tesseract переименуйте в `Tesseract-OCR` и поместите её также в папку `backend`.

9.  Готово! Запускайте собранный `flutter_app.exe` из папки `build\windows\runner\Release`.
